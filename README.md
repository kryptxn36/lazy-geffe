A program doing a routine of cracking a file performing a basic Siegenthaler's attack on a Geffe generator. But if you are using this program you already know what it does anyway.

The target Geffe generator is described by the following Boolean function:\
$F(X_{1},X_{2},X_{3})=(X_{1} \wedge X_{2}) \oplus (\neg X_{2} \wedge X_{3})$

Supported formats:
- .pdf
- .png
- .vsdx
- .docx
- .xlsx
- .pptx

### Usage
```python lazy_geffe.py <encrypted_file(s)> -o <output_path (optional)>```
